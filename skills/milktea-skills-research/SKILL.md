# Milktea Skills Research

把研究工作交給新的背景 Agent，讓呼叫者繼續處理不依賴研究答案的工作。平台無法建立背景 Agent 時，使用隔離的臨時 Agent；兩者皆不可用時回報 `RESEARCH_AGENT_UNAVAILABLE`，不得假裝已查證。

研究 Agent 只做下列工作：

1. 針對交付的明確問題，優先查官方文件、原始碼、正式規格與第一方 API；每個重要主張都追溯到真正擁有該資訊的來源。
2. 把結果寫成一份附引用的 Markdown，不建立第二份摘要或資料庫。
3. 沿用專案既有的研究文件位置；沒有慣例時寫入 `docs/work/<功能名稱>/research.md`，並回報實際路徑。

只交付可查證的事實、必要限制與仍無法確認之處。不得決定需求、架構、產品取捨或是否實作，也不得修改程式。
