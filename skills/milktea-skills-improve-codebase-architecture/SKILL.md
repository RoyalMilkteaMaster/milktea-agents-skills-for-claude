# Milktea Skills Improve Codebase Architecture

啟動後，本 Task 的 Core Agent 立即進入 `Architecture Auditor` 角色，直到報告完成且使用者選擇下一步。完整健檢後再決定是否重構；不得自動修改程式。

## 範圍

- 只分析 Code Root 與必要 Git 歷史。
- 讀取 `AGENTS.md`、`CONTEXT.md`、ADR、架構文件、依賴設定與測試。
- Data／Runtime Root 只讀取已記錄的邊界與設定，不遞迴掃描資料、模型、快取或大型應用程式。
- 工作目錄有未提交變更時照常唯讀分析，但在報告標明。
- 只能寫入本次 HTML 報告與 `CONTEXT.md` 文件索引；不得修改其他專案檔案。

## 流程

1. 記錄專案名稱、日期、Code Root、分支、Git SHA、工作目錄狀態與掃描範圍。
2. 建立目前目錄、模組、公開介面、資料流、依賴與測試接縫地圖。
3. 以 Git 變更頻率與修改耦合找熱點，再查證實際程式責任；不得只憑檔案大小下結論。
4. 找出循環依賴、重複責任、模糊命名、過度分層、淺薄模組、跨邊界存取、巨大模組、失真文件與難測試區域。
5. 每個問題附檔案或模組、證據、影響與信心；區分事實、推論與未知。
6. 提出最少且有實質差異的改善候選；沒有值得重構的問題時明確建議維持現況。
7. 產生並開啟 HTML 報告；無法自動開啟時回報完整路徑。
8. 詢問使用者選擇候選或維持現況。選定後把它視為新需求，交由 `/milktea-agents-army-claude:milktea-skills-grill-me` 規劃；不得直接重構。

## 報告位置

先讀取 `CONTEXT.md`；未指定時使用：

`docs/architecture-reviews/YYYY-MM-DD-<專案名稱>.html`

寫入時才建立目錄。同日同名檔案已存在時追加 `-02`、`-03`，不得覆寫。把實際路徑加入 `CONTEXT.md` 的文件索引。

## HTML 規則

- 使用繁體中文；程式識別字保留原文。
- 單一 HTML 檔；資料、Mermaid 原始碼與報告內容全部內嵌。
- 使用 Tailwind CSS CDN 與 Mermaid CDN；內容即使 CDN 失效仍須可閱讀。
- Mermaid 使用 `securityLevel: 'strict'`，節點文字須安全轉義。
- 提供固定目錄、響應式版面、列印樣式、嚴重度標籤與可收合證據。
- 不貼大量原始碼；引用精確檔案、行號、指令與必要片段。
- 不使用無依據的精確分數、成本或工期。

## 報告內容

1. 執行摘要：是否值得重構、首要問題、推薦候選。
2. 掃描資訊：SHA、狀態、範圍、限制與未讀區域。
3. 現況：目錄骨架、模組責任、資料流、依賴與測試接縫 Mermaid 圖。
4. 熱點：證據、影響、嚴重度、信心與修改耦合。
5. 問題清單：根因、衍生風險與不處理後果。
6. 改善候選：目前／目標 Mermaid 圖、責任變化、影響範圍、效益、成本、風險與限制。
7. 遷移計畫：可回復步驟、相容策略、驗證與回滾。
8. 優先順序：推薦候選、推薦理由、何時不該做。
9. 證據附錄：使用的指令、關鍵輸出與未知事項。

## 判定原則

1. 先確認真問題，不為整齊而搬檔案。
2. 優先簡化資料結構、責任與依賴，再考慮新增抽象。
3. 沿用現有框架與公開契約；向後相容優先。
4. Code、Data、Runtime 邊界不得混淆。
5. 候選必須可分段驗證、可回滾，且改善大於遷移成本。
6. 沒有足夠證據時寫「不知道」，列出補證方法。

## 完成條件

- 報告可開啟，Tailwind 與 Mermaid 正常；無 CDN 時仍可閱讀文字。
- 所有重要結論可追溯到程式、Git、測試或文件證據。
- 報告包含現況、候選、風險、遷移、驗證與回滾。
- 除本次 HTML 報告與 `CONTEXT.md` 文件索引外，未修改來源碼、設定、依賴或外部 Data／Runtime；未 Stage、Commit 或 Push。
- 使用者取得完整路徑並可選擇下一步。
